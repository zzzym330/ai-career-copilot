# 职觉 JobPulse

> 解译职业脉动 —— AI Career Intelligence Platform

职觉（JobPulse）是一个面向求职者的 AI 求职助手，通过大模型将岗位分析、个人职业画像与求职准备串联起来，帮助用户更高效地理解岗位要求、识别自身差距并进行针对性准备。

🌐 **在线体验：** https://ai-career-copilot-three-theta.vercel.app/

## 核心功能

- **JD 解译**：分析岗位职责、核心技能、岗位画像与岗位难度
- **职业画像**：解析用户简历并生成个人能力画像
- **岗位差距分析**：结合 JD 与个人经历，识别匹配优势与能力差距
- **个性化面试题**：根据目标岗位和个人简历生成针对性的面试问题

## 项目设计与 AI 协作

项目从需求分析、产品架构、功能设计、UI/UX 到上线迭代均由本人独立完成。

开发过程中使用 ChatGPT 进行产品方案讨论、Prompt 设计及问题排查，并使用 Codex 辅助代码开发与调试；核心 AI 能力通过 DeepSeek API 实现。在开发过程中持续对模型输出进行测试与优化，并根据真实用户试用反馈调整产品流程和交互体验。
